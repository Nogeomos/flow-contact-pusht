# 第二至第四阶段实验协议

本协议在本轮模型训练和闭环测试之前确定。项目目标是验证二维 PushT 中“期望物体运动 → 接触预测 → 独立控制器”的流程。二维圆形推杆的结果不能直接证明跨机器人本体、真实机器人或三维任务的泛化。

## 数据与分组

- 原始数据：`lerobot/pusht`，固定版本 `7628202a2180972f291ba1bc6723834921e72c19`。206 条完整示范、25,650 帧；原始数据不含物体位姿和接触真值。
- 位姿、接触、64 个固定编号轮廓点来自已核验的物理回放。接触标签表示示范中发生的接触区域，不是“最优接触”或成功概率。
- 使用已有并重新核验的 `data/derived/splits.json`：训练 164 条、验证 21 条、测试 21 条，随机种子 20261022；先按完整示范分组，再构造窗口。
- 八步窗口共 24,000 个：训练 19,130、验证 2,589、测试 2,281。连续窗口可以重叠，但只能在同一个示范分组内。
- 每个窗口包含 9 个物体状态和 8 个动作/接触区间。排除每条示范没有视频端点的最后一个仿真区间；排除包含内部拼接缝接触的无效区间。不得依据成功、误差或图像重合度进一步筛选测试样本。
- 新进程运行 `research/validate_stage2_data.py`，重新检查全部 206 个文件及原始资源哈希；不覆写历史数据和旧报告。实际审计结果在 `runs/stages234_20261022/data_audit.json`。

## 模型输入和防止信息泄漏

训练与离线测试允许使用示范的未来物体运动，作为“给定期望运动时接触能否预测”的条件。所有未来轮廓点都以当前帧的局部坐标系表达，避免把每个未来帧重新对齐后抹除真实运动。

真实闭环测试中，期望 flow 必须由当前物体状态、固定目标与规划器生成。控制器和在线模型不得读取测试示范的未来状态、未来动作或接触。可读取测试示范 ID 来生成已定义的初始状态；这不授权读取示范未来。回放式离线分析和自主闭环执行必须分别报告。

标准化、类别权重、数据增强规则等只能从训练集估计；验证集用于选择超参数、训练轮数和控制器配置。测试集用于最终评估，测试后的方案改动必须注明探索性质，不能把反复挑选后的测试数字冒充未见测试结果。

## 比较方法

1. Flow 条件接触预测：几何和期望运动输入，输出固定轮廓点分数及必要的无接触信息，再交给独立控制器。
2. 简单接触选择规则：与学习方法共享同一控制器、目标、初始条件和执行预算，只替换接触选择方法。
3. Flow → action：几何与期望运动直接预测推杆动作；推杆动作定义为世界坐标中的目标中心位置。
4. 视觉 Diffusion Policy：基于图像和推杆观测生成动作序列。必须记录是否使用官方网络、架构缩小、训练时长和采样步骤等改动；轻量适配实验不得称为论文结果的完整复现。

各方法的信息不同：接触方法可使用仿真提供的准确物体位姿，视觉方法从图像推断。必须在表格中说明这一差别，避免把结果直接归因于算法优劣。控制器如果进行仿真预测，还应记录候选数、预测时长与模型访问权限，并给规则方法同等预测预算。

## 指标与统计

离线接触预测同时报告接触/无接触识别和真实接触区间上的空间误差（如预测点到接触区域的距离），以及软标签误差。全零预测可能获得较低均方误差，不能仅凭总体误差断言接触预测有效。采样数、软/硬标签、运动时间信息消融必须使用相同的示范划分。

闭环主指标是按完整 episode 计算的成功率：执行过程中物体与目标的覆盖率达到 0.95 即成功；同时报告终止时覆盖率、最大覆盖率、步数和失败原因。覆盖率是“物体与目标的相交面积 / 目标面积”，不是交并比，也不等于图像可见轮廓 IoU。当前上游环境使用严格大于 0.95 的终止比较，本协议统计使用大于等于 0.95，须在保存结果时记录两者，避免边界混淆。每种方法使用相同初始 episode 和明确的最大动作步数；到达成功后按相同规则停止。

测试统计单位为独立 episode，不是 2,281 个重叠窗口。21 个测试 episode 的单次成功率变化约为 4.76 个百分点；必须报告成功数/总数。可报告二项比例 Wilson 95% 区间，以及按 episode 配对的覆盖率差值/重采样区间。多随机种子训练若未完成，应明确只有一个训练种子，不能声称结果稳定。

## 解释边界

首轮实验的主要产出是可重跑的数据、训练、控制器和比较流程。学习模型能拟合离线接触，不保证它能处理控制器规划产生的新 flow；这是需要记录的分布偏移。闭环成功率不理想也是实验结果，必须连同轨迹和失败案例展示，不得改写为模型已经学会可靠操作。

每份最终记录明确区分：已运行并保存证据、已实现但尚未验证、后续建议。使用模型权重、配置、代码版本/哈希、实际命令和日志关联结果，不引用计划中的数字作为实测值。
